TioPhill sistema de gerenciamento de lanchonetes e restaurantes.

Funcionalidades por serviço:

* Auth Service:
    * Registrar usuário;
    * Login de usuário;
    * Autenticação;
    * Controle de acesso.

* Menu Service:
    * Criar e editar cardápio;
    * Visualizar cardápio;
    * Inativar/Ativar cardápio promocional.

* Order Service:
    * Criar pedido;
    * Acompanhar andamento do pedido;
    * Balanço de pedidos;
    * Baixa de estoque.

* Stock Service:
    * Criar e editar ingredientes;
    * Controle de quantidade de ingredientes no estoque;
    * Balanço de custo.
